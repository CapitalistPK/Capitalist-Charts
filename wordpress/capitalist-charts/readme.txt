Live Pakistan Stock Exchange widgets for any post or page.

== Description ==

Add live PSX prices, charts, market maps, foreign and local flows, fund cards, corporate events
and more with a shortcode. Free, no sign-up, no API key.

    [capitalist widget="ticker-tape" symbols="PSX:KSE100,PSX:OGDC,PSX:HBL"]
    [capitalist widget="quote" symbol="PSX:OGDC" theme="dark"]
    [capitalist widget="mini-chart" symbol="PSX:LUCK" range="1Y"]
    [capitalist widget="market-map"]

Every widget and its attributes: https://capitalist.pk/widgets

The plugin loads one small script from capitalist.pk. Widgets fetch public market data from
capitalist.pk; no cookies are set and nothing about your visitors is sent beyond the ordinary
request. Data by Capitalist.
